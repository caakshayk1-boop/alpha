# ApexPro — Terminal Modern

## Purpose
An independent Indian equity research workspace: investigate market context, inspect source evidence, compare companies and retain dated personal research. Educational copy; no return claims or recommendations.

## Visual identity
A modern terminal. Graphite surfaces (#0B0C0E canvas, #08090B rail, #121317/#191B20 panels), Apple-grade neutral text (#F5F5F7 / #B6BAC3 / #8F949E) and a single terminal amber (#FFA800) for brand, selection, focus and primary action. Gains mint (#3DDC97) and losses coral-red (#FF6B6B) are always paired with a sign and a value. Caution/stale is a lighter amber (#FFD166). Comparison and links of record use blue (#5AA9FF). This replaces the midnight-blue Research Canvas at the owner's request; the layout, data and features are unchanged.
References: Bloomberg Terminal (density, amber on black, status bar, keyboard-first), Apple (type precision, frosted bars, restraint), Kokonut UI (Geist, 4px grid, mono index codes, micro-interaction timing).

## Tokens
All colour, font-family, radius, timing and easing definitions live in `apps/apexpro/public/tokens.css`. No component defines root tokens. Radius 8px panels / 4px controls.

## Type
Geist variable (self-hosted, SIL OFL) for UI and headings, weights 500–600, tight tracking on large sizes. The existing Mono face carries every number (tabular figures) and the small uppercase labels (11px minimum, .06em tracking). Fraunces remains only for the export/reel assets.

## Density and space
4px grid. Desktop (fine pointer) body 13px/1.5, controls 32px, table rows ~30px, panel padding 12–14px, topbar 44px, rail 176px, 26px status bar. Coarse pointers keep a 44px target floor and 11px text minimum. Each panel heading carries a mono index code (01, 02…) generated by CSS counters.

## Composition
Slim rail with amber edge marker on the active route and 1–4 keyboard hints; frosted sticky command bar (⌘K); persistent status bar carrying independence and the educational disclaimer; canvas home (sector × horizon matrix, scoped candidates, company preview) unchanged. Company, Discover, Compare and Desk inherit the same shell.

## Interaction
Keys 1–4 open Canvas, Discover, Compare, Desk when no field has focus. ⌘K opens the command palette. Back links point back. The trend badge states what Mixed/Uptrend/Downtrend mean (title + focusable). Selection rows show an amber cursor edge.

## Motion
Three one-shot moments: content rises 6px over 320ms on route entry with a 30ms stagger, the active-route marker grows over 320ms, matrix cells brighten on hover over 120ms. Existing route/Flip/Lenis/bar motion unchanged. Nothing loops except the fresh-session pulse. Reduced motion disables all of it.

## Accessibility and data truth
Native controls, visible amber focus ring, selected state in text/ARIA. Every missing number stays missing; confidence is numeric as well as visual. No API, score, vet or ladder changes. All persisted keys and Desk data preserved.

## Assets and release
Geist and Mono self-hosted; icons from the local 24px sprite (arrow-left added). Vanilla ES modules; CSS compiles from src/app.css + src/canvas.css + src/modern.css into one app.css plus tokens.css. Strict CSP unchanged. Every release updates SW VERSION and SHELL together (this release: v13-terminal).
