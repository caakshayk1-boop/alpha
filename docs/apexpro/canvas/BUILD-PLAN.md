# ApexPro Research Canvas
User delegated a full replacement after rejecting successive generic dashboard refinements. Keep research data, persistence and every existing company tool. Replace the home composition and the app's visual hierarchy.

Direction: midnight-blue workspace with an ink-blue navigation rail, pale blue primary actions and a warm apricot selection marker. The main canvas is a sector × horizon return matrix; selecting a sector scopes a research list and a company preview. Tabs represent explicit research criteria, not inferred recommendations. The preview is a compact dossier with price location, score confidence and source countercase. A review queue reconnects saved research. Existing deep tools remain under Advanced research.

New functionality: sector focus in place, four horizon medians with coverage tooltips, five named research lenses, six-row pagination, company quick preview, same-context CSV export, shortlist follow and compare, dated review queue. All computed from existing screen rows; missing values remain missing. No new endpoint/model logic.

Motion: selected-row background transition and preview opacity, existing route morphs; no autoplay charts or decorative loops. Reduced motion removes transitions. Proof: model tests for lenses/medians/export, browser flows and all-route regression, axe both palettes, warm-cache migration and live checks.
