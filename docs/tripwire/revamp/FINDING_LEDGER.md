## Not covered by a test in this branch

- Real-device behaviour: haptics, the platform authenticator, safe-area and keyboard behaviour of sheets, 200% zoom, screen-reader speech (the accessible names and roles are checked, the speech is not heard), and any frame-rate or Core Web Vitals claim.
- `beta.mjs` "slowest interaction under 200 ms" is a lab figure that varied between 160 and 408 ms between identical runs in this sandbox (it also read 200 ms on the first build of this work); it is noise-limited here and is not claimed as passing.
